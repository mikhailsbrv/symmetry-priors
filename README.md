Разобрал RSA, мы по факту сравниваем относительную геометрию активаций для больших и маленьких букв

Если есть какой-то один обобщающий механизм, то RSA будет высоким, но из высокого RSA обратное не следует

Метод который я на коленке за пару минут придумал будет лучше.

Берем одну букву, берем два батча картинок этой буквы по батчу на букву. Каждый элемент i b1[i] b2[i] имеет одинаковые горизонтальные и вертикальные смещения
Выбираем узлы графа, (например, выход голов внимания), получаем усредненную активацию по каждому из батчей, два вектора r1 r2
Нормализуем и центрируем r1 и r2
Векторно умножаем r1 и r2, получаем вектор g
Делаем шаги 1-4 для всех букв
На этом шаге мы имеем 26 векторов g. Теперь каким-нибудь методом получаем корреляции поэлементные между этими векторами. Места с наивысшей корр это "внутренние узлы, которыми нейросеть понимает масштаб"
Скорее всего это тупо и здесь найдутся ошибки, но в целом +- похожий подход развить и использовать имеет смысл

Если что, цель найти внутренний общий механизм масштаба для трансформера, если найти его зачатки, то имеет смысл задать его как явный приор, либо в арх, либо при обновлении весов или еще как. Если общего механизма нет, что +- пока что следует из моего недоэксперимента на узких синтетических данных, то это основание выдвинуть гипотезу "ViT распознает большие-маленькие объекты как объекты разных классов" с которой дальше можно работать
